# Brand-First — Read the Brand Before You Act

**Applies to:** every marketing skill, every agent, every brand. This is the highest-leverage convention in the library.

## The rule

Before asking the owner a single question, read the brand's context files in `agency/brands/<slug>/`:

- `brand-voice.md` — how the brand sounds, banned phrases, rejection patterns
- `audience.md` — who it's for, what they want, their language
- `offers.md` — what it sells, price points, guarantees
- `learnings.md` — what already worked and failed for this brand

Use that context. **Only ask for what's genuinely missing.** Every question you ask the owner that a file already answered is trust burned.

## Why it matters for a white-label agency

The agency runs many brands with one operating system. The only thing that keeps Brand A from sounding like Brand B is that every skill reads the brand's files first. The skills are shared; the context is per-brand. This convention is what makes white-label possible.

## Skill authoring rule

Every new marketing skill must start its workflow with: "Read the brand context files; proceed from there; ask only for what's missing." If a skill can't state which brand files it needs, it's not ready to be added to the library.

## When context is stale

If the brand files contradict what you observe in recent data (voice drift, audience shift), flag it to the owner with specifics — don't silently overwrite. Stale context is a loop failure, not a reason to skip the read.
