## What OpenMontage is (in our own words)

OpenMontage is a self-described "world's first open-source, agentic video production system": 12 production pipelines, 100+ tools, 700+ agent skill and production-knowledge files. An AI coding assistant (Claude Code, Cursor, Copilot, Windsurf, Codex) drives the whole production: research, scripting, asset generation (real stock footage or generated), editing, narration, music, burned-in word-level subtitles, and Remotion/FFmpeg/Blender rendering. Ships pipeline definitions, provider scoring with decision audit trails, budget controls, quality gates, and a "Backlot" living storyboard with approval gates and run replay. ~61k stars, 449 commits, v0.8.x-era activity in September 2026.

## Why it was excluded

The GitHub license page for calesthio/OpenMontage reports **GNU Affero General Public License v3.0 (AGPL-3.0)** (README badge: License-AGPLv3). AGPL network copyleft is incompatible with the white-label agency model. Per the SOURCES.md vet rule, AGPL repos are described, never copied — regardless of popularity.

## If the license ever changes

Re-evaluate only if the project relicenses to MIT/Apache-2.0 without carve-outs. Do not re-evaluate on star count alone — re-read the LICENSE file.
